# VibeTalk Audio Lab

iOS Audio Denoise Benchmark application for comparing RNNoise, DeepFilterNet2 Lite, and DeepFilterNet3 algorithms.

## Features

- Record audio from microphone
- Stream process audio through three denoise algorithms
- Measure Time To First Audio (TTFA)
- Compare latency and performance metrics
- Blind A/B testing mode
- Continuous streaming test
- Hardware benchmarking (iPhone 12 vs iPhone 14 Pro)

## Requirements

- iOS 15.0+
- Swift 5.9+
- Xcode 15+
